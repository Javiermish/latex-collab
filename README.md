# LaTeX Collab

A self-hosted collaborative LaTeX editor with real-time synchronization between Neovim and web browsers.

## Overview

LaTeX Collab aims to provide a collaborative LaTeX editing environment while preserving Neovim as the primary editor for the host.

## Goals

- Real-time collaborative editing
- Bidirectional synchronization with Neovim
- Browser-based editor for collaborators
- Local LaTeX compilation and PDF preview
- Self-hosted architecture
- Secure remote access

## Tech Stack (Planned)

- TypeScript
- Node.js
- CodeMirror 6
- Yjs
- Neovim Lua API
